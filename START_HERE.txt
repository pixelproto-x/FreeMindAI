FreeMind AI — 開始使用

1. 將 FreeMindAI.zip 解壓縮到一個資料夾。
2. Windows 使用者雙擊 run.bat。
3. 第一次啟動會建立 Python 環境、安裝依賴，並開啟 .env 設定檔。
4. 在 .env 裡填入你自己的 API Key，至少啟用一家服務（例如 GROQ_API_KEY 或 GEMINI_API_KEY）。儲存並關閉記事本。
5. 回到黑色命令視窗，按任意鍵繼續；啟動後打開 http://127.0.0.1:8080。
6. 關閉黑色視窗即可停止程式。

注意：API Key 只應保存在本機 .env 或託管平台的私密環境變數裡，不要提交至 GitHub，也不要貼在公開聊天室。
雲端 AI 服務各自有免費額度與使用規則；備援只能切換服務，不能解除服務商限制。
不想使用本機運算時，不要填入 OLLAMA_MODEL。若要不依賴自己的電腦運作，需要部署到雲端主機；穩定的持久化部署可能需要付費。

測試：在已安裝開發依賴的環境中執行 python -m pytest -q。
完整操作與雲端部署說明請閱讀 README.md。
